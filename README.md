# Steam Deck Rewards CLI

A simple Python command-line utility to register and claim Steam Deck profile rewards directly through the Steam API (`ILoyaltyRewardsService#RegisterForSteamDeckRewards`). Built as part of the [steamcommunitykit](https://github.com/steamcommunitykit) organization.

## Features

- **Interactive CLI:** Straightforward prompts for credentials and device IDs.
- **Fast Execution:** Directly hits the Steam API endpoint to apply rewards to your account.
- **Lightweight:** Powered by Python and standard `steamcommunitykit` login methods.

## Prerequisites

- Python 3.8+
- `steamcommunitykit` (Ensure you have the required library installed for Steam authentication)
